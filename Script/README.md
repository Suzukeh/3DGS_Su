# 3DGS_Su

> [!WARNING]
> **開発のごく初期段階です。** 機能は不完全で、予告なく仕様やファイル形式が変わったり、
> 動作しなくなったりする可能性があります。大事なプロジェクトでは、事前にバックアップを取ってから
> お使いください。

3DGS（3D Gaussian Splatting）の PLY / SOG を AviUtl2 の 3D 空間に表示する
カスタムオブジェクトです。カメラ制御に合わせて動きます。

## AI利用について

スクリプトの一部はAIによって作成されています。問題や改善については私の責任感に従い誠実な対応をするつもりですが、私の能力を超えて対応不能なケースが生じうることをご理解ください。

## 使い方

1. カスタムオブジェクト `3DGS_Su` をタイムラインに追加し、選択する
2. **表示 → 3DGS変換** で専用ウィンドウを開く
3. **ファイル参照...**（または **SOGフォルダ...**）で `.sog` / `.ply` を選ぶ
4. **品質テンプレート** を選び、**変換して適用** を押す

| テンプレート | 向いている用途 |
|---|---|
| プレビュー（最大3万点） | 配置やカメラワークの確認。軽い |
| バランス（最大15万点） | 普段の作業 |
| 品質保持（全点） | 仕上げ。変換と描画に時間がかかり、メモリも多く使う |

大きさ・向き・表示上限などは、ウィンドウの **変換の詳細設定** と **表示設定** を開いて調整できます。
表示が重いときは **表示上限** を下げてください（0は全点）。

`3DGS_Su` の後に付けたフィルタ効果は反映されません。

詳しい説明・作例・不具合の報告先は
[GitHub のページ](https://github.com/Suzukeh/3DGS_Su) を参照してください。
