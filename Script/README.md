# 3DGS_Su

3DGS（3D Gaussian Splatting）の PLY / SOG を AviUtl2 の 3D 空間に表示する
カスタムオブジェクトです。カメラ制御に同期して動きます。

同梱の `3DGSConverter_Su` プラグイン（汎用プラグイン）で、`.sog` / `.ply` を
`.su3ds` に変換できます。Python は不要です。

## 使い方

1. `3DGS_Su` オブジェクトを追加する
2. オブジェクトを選択し、**編集 → 3DGS変換 → 「3DGSを変換して適用...」**
3. `.sog` / `.ply` を選ぶ

詳しい説明・パラメータ・ライセンスは
[リポジトリの README](https://github.com/Suzukeh/3DGS_Su) を参照してください。
