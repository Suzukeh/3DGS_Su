# 3DGS_Su

3DGS（3D Gaussian Splatting）の PLY / SOG を AviUtl2 の 3D 空間に表示する
カスタムオブジェクトです。カメラ制御に同期して動きます。

同梱の `3DGSConverter_Su` プラグイン（汎用プラグイン）で、`.sog` / `.ply` を
`.su3ds` に変換できます。

## AI利用について

スクリプトの一部はAIによって作成されています。問題や改善については私の責任感に従い誠実な対応をするつもりですが、私の能力を超えて対応不能なケースが生じうることをご理解ください。

## 使い方

1. `3DGS_Su` オブジェクトを追加する
2. オブジェクトを選択する
3. `3DGS変換` ウィンドウで `.sog` / `.ply` またはSOGフォルダを選ぶ
4. **軽量**／**品質優先（追加間引き・量子化なし）**を選び、**変換して適用** を押す

品質優先は有効な全点、浮動小数点の色・不透明度、入力に含まれるSHを保持します（SHは既定でオン）。処理時間とメモリが増えます。元のビューアと完全に同じ画素になる保証はありません。

正規化、元のサイズ、倍率、中心、軸反転、ディザ、SH、出力先、表示上限、合成なども専用ウィンドウから設定できます。表示上限0は全点です。コマンド入力は不要です。

ウィンドウを閉じた場合は **表示 → 3DGS変換** またはオブジェクトの右クリックから開き直せます。

詳しい説明・パラメータ・ライセンスは
[リポジトリの README](https://github.com/Suzukeh/3DGS_Su) を参照してください。
