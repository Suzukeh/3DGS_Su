# 注意・制限

[READMEへ戻る](../README.md)

- 表示できる点数の目安はおよそ3万点です。200万点級の風景スキャンは、間引くと細部が失われます。
- 通常合成は点単位の painter's sort です。点が交差する場面では完全な前後関係になりません。
- オブジェクト自体の回転・拡大は点群全体に掛かります。
- 色は512色、不透明度は8段階です。
- 視点依存のSH色は使いません。PLY / SOG のDC成分のみです。
- パノラマモードは360度スキャン向けの簡易的な球面投影です。通常の3Dシーンではオフにしてください。
- 変換専用UIの **点数の上限** と、オブジェクト設定の **表示上限** は別です。前者は `.su3ds` に保存する点数、後者は実際に描画する点数です。
- 変換は入力ファイルと同じフォルダへ `.su3ds` と `.json` を書き出します。既存ファイルは上書きされます。
