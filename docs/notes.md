# 注意・制限

[READMEへ戻る](../README.md)

## 後に付けたフィルタ効果は効かない

描画方式の都合で、`3DGS_Su` オブジェクトの後に付けたフィルタ効果は反映されません。

## 重いとき

- **表示上限** を下げると、プレビューが軽くなります。仕上げのときは **0（全点）** に戻してください
- 品質テンプレートを **プレビュー** や **バランス** にして変換し直すと、さらに軽くなります
- 品質保持は、変換ファイル・メモリ・描画時間がいずれも大きくなります。リアルタイム再生できるとは限りません
- 変換時に減らした点は、あとから表示上限を上げても戻りません。必要なら元ファイルから変換し直してください

## 画質について

- 品質保持でも、元のビューア（SuperSplat など）と完全に同じ見た目になるわけではありません。描画方法の違いによる差が残ります
- 元データにない情報は増えません。SOG はもともと圧縮された形式なので、その分の劣化は戻りません
- 点どうしの前後関係は、点の中心の距離で決めています。重なり方によっては、前後が不自然に見えることがあります
- パノラマ表示は簡易的な球面表示です。通常の 3D 表示とは見え方が異なります

## 変換について

- 大きなファイルの変換には時間がかかります。進み具合はウィンドウ上部に表示され、**中止** でいつでも止められます
- 読み込みの途中では、中止が効くまで少し待つことがあります
- 見る角度による色の変化（SH）は、3次までのデータに対応しています。それより高次のデータはエラーになります
