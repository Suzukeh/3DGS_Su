# .su3ds ファイルについて

[READMEへ戻る](../README.md)

`.su3ds` は、PLY / SOG を 3DGS_Su で表示するために変換した専用ファイルです。
一般的な 3DGS ビューアでは開けません。

PLY / SOG を毎回読み直さずに済むため、プロジェクトを開いたときやプレビュー中の表示が速くなります。

## 軽量と品質優先

変換形式によって、保存する内容が変わります。

| | 軽量 | 品質優先 |
|---|---|---|
| 使うテンプレート | プレビュー・バランス | 品質保持 |
| 点の数 | 上限まで減らす（上限なしも可） | 全点 |
| 色・不透明度 | 簡略化（512色・8段階） | 元データのまま |
| 見る角度による色の変化（SH） | 保存しない | 元データにあれば保存 |
| ファイルサイズ | 小さい | 大きい |

どちらの形式も、同じ `3DGS_Su` オブジェクトで表示できます。以前のバージョンで変換したファイルも使えます。

## 扱い方

- 変換と同時に、同じ名前の `.json` ができます。元ファイル名や点数などの記録で、表示には使いません
- 元の PLY / SOG は残しておいてください。品質や向きを変えるときは、元ファイルから変換し直します
- **変換して適用** で同じファイル名に変換し直すと、設定したオブジェクトの表示も更新されます。ほかのオブジェクトで同じファイルを使っていて表示が古いままのときは、**再読み込み** を 0→1 にしてください
