# .su3ds とは

[READMEへ戻る](../README.md)

`.su3ds` は、PLY / SOG を3DGS_Suで描画しやすい形へ事前変換した専用のバイナリファイルです。一般的な3DGSビューアで開くための形式ではありません。読み込んだデータはキャッシュされ、毎フレーム元のPLY / SOGを解析し直すことはありません。

## 軽量と品質優先

| 内容 | 軽量（v1） | 品質優先（v2） |
|---|---|---|
| 点数 | 指定した上限まで。上限なしも選択可能 | 有効な全点を保持 |
| 色 | 512色 | 浮動小数点RGB |
| 不透明度 | 8段階 | 浮動小数点 |
| 視点依存色（SH） | DC成分のみ | 入力に含まれる係数を保持 |
| 処理負荷 | 比較的軽い | 高い |

どちらも位置と共分散を保存します。品質優先では、読み込み後の描画でも保存した色・不透明度・SHを使用し、軽量版のパレットへ戻すことはありません。旧形式のファイルも引き続き読み込めます。

## 元データとの関係

- 変換後のファイルは繰り返し使えます。点数や変換設定を変える場合は再変換してください。
- 元のPLY / SOGは残してください。軽量変換で省いた点や情報は、表示上限を上げても戻りません。
- 正規化や軸反転などは変換設定に従って反映されます。元の座標スケールを保つ場合はUIで「元のサイズを保つ」を選びます。
- 同名の `.json` に変換情報を記録します。
- 品質優先は追加の間引き・色／不透明度の量子化を避ける設定です。SOG自体の圧縮やAviUtl2の描画精度を元に戻す設定ではありません。
