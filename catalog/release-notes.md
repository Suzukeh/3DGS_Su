# 3DGS_Su v0.5.1

AviUtl2のカメラ制御に同期してPLY / SOGの3DGSを表示するカスタムオブジェクトと、専用変換プラグインです。

## 追加・変更

- **品質テンプレート3種類**：プレビュー（最大3万点）、バランス（最大15万点）、品質保持（全有効点・浮動小数点の色と不透明度・SH）から選べます。
- **同じ素材・同じ視点の比較作例**：各テンプレートで360度を1周する1280×720・30fpsのMP4を用意しました。色の比較用のRGBロスレス版と、再生互換性を優先した通常版があります。全体図、細部の拡大図、点数と容量の比較も掲載しています。[品質テンプレートと比較作例](https://github.com/Suzukeh/3DGS_Su/blob/main/docs/quality-presets.md)
- **ウィンドウ配置を修正**：専用UIがほかのパネルを覆う問題を修正し、AviUtl2の保存済みレイアウトに従うようにしました。
- **詳細設定を折りたたみ**：変換の詳細設定と表示設定は、初期状態で閉じています。個別の調整項目は引き続き利用できます。
- テンプレートの選択では、位置・大きさ・向き・入出力先など、品質以外の設定を保ちます。
- テンプレートによる変換・適用時は、変換後の全点を表示するよう表示上限も反映します。
- 従来の変換済み `.su3ds` を引き続き利用できます。

## 使い方

1. `3DGS_Su` オブジェクトを追加して選択します。
2. **表示 → 3DGS変換** で専用ウィンドウを開きます。
3. 入力と品質テンプレートを選び、**変換して適用** を押します。

## 注意

品質保持は時間とメモリを多く使います。元ビューアとの画素の完全一致や、元データ自体の完全保存を保証するものではありません。元のPLY / SOGも保管してください。
