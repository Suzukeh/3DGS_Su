# 3DGS_Su v0.5.2

AviUtl2のカメラ制御に同期してPLY / SOGの3DGSを表示するカスタムオブジェクトと、専用変換プラグインです。

> **開発のごく初期段階です。** 機能は不完全で、予告なく仕様やファイル形式が変わったり、動作しなくなったりする可能性があります。大事なプロジェクトでは、事前にバックアップを取ってからお使いください。

## 追加・変更

- **変換を中止できるようにしました**：変換中に **中止** ボタンを押すと処理を中断します。中止したときは出力ファイルと `.json` を作らないため、中途半端なファイルが残りません。
- **進捗を表示**：読み込み／変換／書き出しの段階と、変換の割合・処理済みの点数を表示します。読み込み中は所要時間が読めないため、進捗バーが流れる表示になります。
- **小さい画面で使いやすく**：狭いパネルでは入力欄が全幅になり、参照ボタンが次の行へ回ります。**変換して適用** などの実行ボタンと状態表示はウィンドウ下端に固定し、進捗と **中止** は上端に固定したため、内容をスクロールしていても操作できます。
- **終了が速くなりました**：変換中に AviUtl2 を閉じても、完了を待たずに終了します。
- README の冒頭に、開発初期段階である旨の注意を追加しました。

## 使い方

1. `3DGS_Su` オブジェクトを追加して選択します。
2. **表示 → 3DGS変換** で専用ウィンドウを開きます。
3. 入力と品質テンプレートを選び、**変換して適用** を押します。

品質テンプレート（プレビュー／バランス／品質保持）と比較作例は
[品質テンプレートと比較作例](https://github.com/Suzukeh/3DGS_Su/blob/main/docs/quality-presets.md) を参照してください。

## 注意

品質保持は時間とメモリを多く使います。元ビューアとの画素の完全一致や、元データ自体の完全保存を保証するものではありません。元のPLY / SOGも保管してください。
