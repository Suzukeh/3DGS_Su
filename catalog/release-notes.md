# 3DGS_Su v0.5.0

AviUtl2のカメラ制御に同期してPLY / SOGの3DGSを表示するカスタムオブジェクトと、専用変換プラグインです。

## 追加・変更

- **品質優先モード**：有効な全点、float32の色・不透明度、入力のSH（degree 3まで）を保持し、描画にも反映します。追加の間引き・512色／8段階への量子化は行いません。
- **設定を専用UIへ集約**：品質、点数、正規化／元のサイズ、倍率、中心、軸反転、ディザ、SH、出力先、表示設定をAviUtl2内で操作できます。コマンド入力は不要です。
- 変換をバックグラウンドで実行し、既存ファイルの上書き前に確認します。シーンやプロジェクトが変わった場合は自動適用しません。
- 表示上限は **0で全点**。品質優先の自動適用時は全点表示に設定します。
- 同じ出力先へ再変換した場合も表示を更新します。
- 従来の軽量モードと変換済み `.su3ds` を引き続き利用できます。
- 終了時の専用ウィンドウの後処理を修正しました。

## 使い方

1. `3DGS_Su` オブジェクトを追加して選択します。
2. **編集 → 3DGS変換...** で専用ウィンドウを開きます。
3. 入力と画質を選び、**変換して適用** を押します。

## 注意

品質優先は時間とメモリを多く使います。元ビューアとの画素の完全一致や、元データ自体の完全保存を保証するものではありません。元のPLY / SOGも保管してください。
